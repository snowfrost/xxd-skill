# XXD 矢量旅行海报（VOL.050 蒸馏）

把随手拍的不太好的照片，处理得专业且色彩和谐。一条街为什么让人想停下来，一个角落为什么看着就很松弛——下半张把照片里的核心对象重新整理成一张旅行视觉海报。

## 核心提示词（中文版，可直接复制）

```
🤣🤣🤣
请将我上传的每一张照片分别制作成一张独立的高级设计海报，不多图拼接，每张照片单独输出。整体采用3:4竖版构图，上下两个区域高度严格1:1，各占画面50%。

上半部分保留原始照片，保持主体身份、结构、姿态、真实质感、自然光影和原有色彩氛围，仅进行轻微高级摄影调色，使其具有艺术杂志、独立出版物与展览摄影质感。为适配画幅，可自然扩展天空、地面或环境背景，但不得拉伸、扭曲或改变主体。

下半部分提取照片中最具识别性的主体、轮廓、姿态与叙事关系，重构为一张 premium minimalist flat-vector travel poster 风格的场景化插画。不要机械描摹照片，而是根据原图的视觉个性，提炼一个最具代表性的主视觉焦点，并围绕它补充 2–4 个最能说明环境气质、日常方式、地方感或生活状态的辅助元素。无论原图是城市、建筑、人物、动物、植物、器物、交通工具或自然景观，下半部分都应像为它量身定制的一张高级旅行视觉海报，而不是套用固定模板。

构图应根据主体本身的气质重新组织，而不是重复同一种版式。利用一个明确焦点、清晰前后层次、适度留白和安静有序的视觉节奏建立画面；可根据原图自然转化为街道、广场、岸边、庭院、通道、平台、植物场景、室内角落、开放景观或带有生活线索的环境片段。主体始终是第一视觉中心，其余元素仅用于强化"这是这个地方 / 这个对象 / 这种情境"的独特性，避免拼贴式地标堆积、明信片式罗列和过度叙事。若画面需要人物，仅保留 3–6 个小尺度人物，并让其自然融入环境，不设单一主角。

整体风格采用高级极简扁平矢量插画：日系文具感、精品贴纸插画、现代 editorial travel branding 气质，使用简洁几何形、柔和轮廓、统一线重、平涂色块和克制细节，画面清新、安静、精致、当代。避免写实、厚重阴影、水彩肌理、纸张纹理、复杂笔触、渐变、拥挤背景和过多细节。

配色以柔和、通透、略微去饱和的高级色系为基础，可从原图中提炼综合色温进行调整，但整体保持轻盈统一。以浅粉蓝、雾蓝、天空蓝、空气感冷调蓝营造主氛围，再以象牙白、奶油白、浅米色、柔和灰绿、建筑中性色保持平衡；仅允许少量 dusty rose 或 muted blush 作为微小点缀，用于花、服饰、小标识、遮阳篷或局部装饰，使画面既有呼吸感又不失精致层次。

文字逻辑也要转化为这种风格的一部分。不要直接套城市名模板，而是从原图的地点、对象名称、主题词、状态或氛围中提炼一个简短标题，置于左上或留白充足的位置，并搭配一句简短、克制、具有气质的 tagline。文字应保持 understated、editorial、spacious、premium 的排版气质，不压过画面；必要时可加入少量小字信息、坐标式注释或微型说明，使文字像高级旅行品牌或精品明信片中的视觉标识，自然融入构图，而不是后期贴上的标题栏。

整体呈现应像一张为该主体专门设计的高级旅行海报 / 精品生活方式明信片：清新、优雅、安静、现代、精致，具有充足留白和松弛的在场感。每一张下半部分都必须拥有独立的视觉身份，不能只替换名称而沿用同一套构图、同一套前景和同一套物件摆法。避免模板感、复制感、通用旅游海报公式和重复性构图。
🤣🤣🤣
```

## 风格要点

| 层 | 内容 |
|---|---|
| 结构 | 3:4 竖版，上下 1:1 各 50%；上保真摄影，下风格化重构 |
| 构图 | 单一焦点 + 清晰前后层次 + 适度留白 + 安静秩序；3-6 个小人物无主角 |
| 风格 | 日系文具 / 精品贴纸 / editorial travel branding；简洁几何、统一线重、平涂色块 |
| 配色 | 浅粉蓝/雾蓝/天空蓝/空气冷蓝 + 象牙白/奶油白/浅米色/柔和灰绿 + 少量 dusty rose |
| 文字 | 简短标题 + 克制 tagline；understated / editorial / spacious / premium |
| 禁忌 | 写实、厚重阴影、水彩肌理、渐变、拥挤背景、模板感、明信片式罗列 |
