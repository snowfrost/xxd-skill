# XXD 词义视觉化 · 大字概念海报

看到一张 GPT2 对 love 这词的视觉呈现，直击心趴——任何词、任何文字，无论英语还是中文，都可以视觉化呈现。核心思想：**文字本身就是主题，图像是对文字的深化表达，二者共同组成一个完整的视觉句子**。

## 两个版本

- **无地面版**：极简概念海报，文字 + 图像隐喻，适合纯视觉表达
- **有地面版**：增加"承载面"机制（舞台/土地/台基/底座），角色能真正站住，画面更有稳定感和叙事性

## 核心机制

| 机制 | 说明 |
|---|---|
| 语义理解 | 先分析词的字面义/情绪气质/文化联想/象征/心理感受/语义张力 |
| 构图 | 极简主场景 + 承载面 + 1-3 个演绎主体 + 巨型文字骨架 |
| 文字嵌入 | 主体站字前/嵌入字内/字为背景墙/字被切割遮挡穿越借位 |
| 色彩 | 1 强主色 + 1 纸感浅色/低彩中性色 + 1 深色支撑 + 1 极少量强调色 |
| 质感 | 拼贴/丝网/石版/版画/纸张颗粒/克制噪点；印刷海报气质 |
| 禁忌 | 字效海报、文字贴背景、假署名假编号假坐标、模板海报、廉价商业风 |

## 完整提示词（有地面版节选，核心骨架）

```
你要生成的不是普通插画，也不是简单把一个单词放大后贴在画面上的字效海报，而是一张"基于词语含义进行视觉转译"的高级概念海报。这张海报必须具备真正优秀的设计思维：文字不是贴上去的说明，图像也不是独立存在的插画。文字、图像、构图、色彩、空间、承载面、角色动作、视觉隐喻，必须共同组成一个完整、聪明、克制、极简但有力的视觉表达。

核心任务：用户会提供一个字、一个词、一个词组、一个短句，或一组字母。你需要先理解这个词语的字面意思、情绪气质、文化联想、隐含象征、心理重量、社会语境与潜在张力，然后把它转译成一张极简而强烈的图形艺术海报。

构图机制（必选）：
1. 必须有一个清晰的承载面：画面中应尽量出现一个明确的横向承载结构，像舞台、土地、台基、坡面、切面、地平线、平台、表层、底座或简化的场域。它不是背景装饰，而是让角色和物体真正"站住"的空间基础。
2. 必须有少量但关键的演绎主体：主体数量克制，1-3 个关键角色或核心物体，通过姿态、朝向、距离、动作、对峙、给予、接触、等待、穿越、凝视、阻隔等关系演绎词语含义。
3. 必须有大字作为画面骨架：用户输入的文字成为主视觉骨架，像背景墙、视觉压力面、建筑块、空间屏障、象征场、秩序边界或情绪载体。
4. 必须体现"文字嵌入"逻辑：文字不能漂浮在背景上，必须真正参与构图——主体站在字前、嵌入字内、字为背景墙、字被切割遮挡、文字与承载面/留白/主体共同构成完整视觉句子。

色彩逻辑：颜色数量控制在 2-4 种主色关系内；优先"一个强主色 + 一个纸感浅色/低彩中性色 + 一个深色支撑 + 一个极少量强调色"；采用纸张印刷感、展览海报感、艺术出版感的配色系统；避免廉价渐变、彩虹色、霓虹、脏浊互撞。

视觉风格：高级图形艺术海报，允许克制拼贴感/石版印刷感/丝网印刷感/版画感/纸张颗粒/轻微噪点；强烈平面设计感、强整体性、收藏级完成度；所有细节围绕"少而精、准而狠"。

文字系统：用户输入的核心文字必须是主标题且是主视觉核心；辅助文字必须与主题直接相关、克制少量巧妙；严禁假署名/假编号/假坐标/随机短句/装饰性小字。

最终目标：一眼有冲击；二眼能读懂；三眼觉得巧妙；图与字高度咬合；真正把词语"视觉化"而不是"插图化"。

请根据以上规则，围绕用户输入内容生成画面。
用户输入内容：
核心文字 / 单词 / 词组 / 字母：______
文字语言：______
可选补充语境：______
可选情绪倾向：______
可选禁用元素：______
```

## 衍生版：大字人物概念海报

同一方法论可用于人物：巨大中文大字做骨架 + 艺术化人物肖像 + 少量精准小字（每行 ≤8 字），文字与人物互相咬合。风格允许：高级平面插画/丝网/版画/石版/国潮图形/现代平面肖像/符号化剪影。
