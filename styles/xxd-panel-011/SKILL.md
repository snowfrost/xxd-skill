# XXD Panel 011 · 哲思极简连续线条

Turn each supplied photograph into a finished philosophical minimal-line artwork. Preserve the real photograph only in paired modes; every transformed frame must retain the same source's identity, pose, relation, and defining structure while distilling its emotional tension, spatial relation, action direction, distance, state, or metaphor into one core visual proposition. A few fine flowing black continuous lines and a great field of silence make the result recognisable without tracing and spiritually deeper without inventing meaning.

Operational rules follow the shared XXD Panel workflow contract: four combinable modes; source-adaptive ordinary canvases; exact 50/50 paired geometry; linked or independent four-device wallpapers; copy and locale preflight; fresh generation jobs; privacy-preserving raster generation; and one fresh task directory per source and mode. Style-specific sections may refine aesthetics, copy hierarchy, and acceptance criteria but never override this contract.

## Non-negotiable contract

- One source photo may be processed in one or more selected modes. Each selected ordinary mode (`top-bottom`, `left-right`, `design-only`) produces one PNG; selected `wallpaper-pack` produces exactly four separate PNGs. Selecting all four modes therefore produces seven final files per source. Keep every mode in its own task directory and never combine modes, sources, or wallpapers into a grid, contact sheet, or overview.
- Resolve a non-empty ordered set of modes before generation: `top-bottom`, `left-right`, `design-only`, and/or `wallpaper-pack`. Accept one choice, multiple choices separated by `+`, Chinese/English commas or whitespace, natural-language names, or `全部` / `all`. Deduplicate repeated choices and execute in menu order 1→4. If none is specified, ask with the multiline multi-select menu in the workflow. Do not ask again when the set is already clear.
- When the selected set contains `wallpaper-pack`, require a second choice: `linked` or `independent`. A linked pack approves one anchor wallpaper, iPad by default, and makes every other device reference both the original photo and that same anchor. An independent pack gives every device only the original photo. Neither permits resizing or cropping one wallpaper into the others. Do not ask this follow-up when wallpaper mode is not selected.
- Paired modes split exactly 50/50. `design-only` and every wallpaper contain no visible source photograph, no seam, and no reserved photographic panel.
- Exact user pixels have highest priority, followed by an explicit ratio or destination. Otherwise ordinary modes adapt to the complete source: `top-bottom` = `W×2H`, `left-right` = `2W×H`, and `design-only` = `W×H`. Never impose the archived initial brief's 3:4 canvas as a silent default.
- Visible photography remains faithful. Allow only restrained editorial grading and environmental extension needed for an explicitly overridden canvas. Never stretch, distort, repaint, replace, or structurally alter the subject.
- The transformed frame must preserve source identity through at least three specific cues while converting pose, relation, emotional tension, direction, distance, state, or supported metaphor into one core image and a sparse system of fine flowing black continuous lines. It is not tracing, decorative one-line art, meaningless abstraction, a generic icon, cartoon, glossy vector, photoreal painting, 3D render, or unrelated flourish.
- Copy has no silent default. Resolve automatic copy, exact custom copy, or text-free output before image generation. Automatic and custom modes also require a target language or locale. By default, one source-specific copy package is shared verbatim across all selected modes; explicit per-mode copy instructions override it.
- Render no logo, watermark, signature, colour swatch, UI, device mockup, decorative pseudo-text, or unrelated explanatory prose.

## Aesthetic motive lock

Modes and device ratios may change placement and aspect ratio but never the 011 motive. Every transformed frame must visibly express this chain:

**this exact photographed subject or inseparable relationship → preserve at least three identity, contour, pose, action, structure, or relation cues → identify its most meaningful emotional tension, spatial relation, action direction, distance, state, or supported metaphor → delete redundancy and compress it into one core visual proposition → rebuild it with a few fine flowing natural black continuous lines whose pauses, breathing, density, and rhythm carry meaning → use omission, local connection, misalignment, extension, overlap, crossing, and unfinished edges only when source-earned → keep one core image, one relation group, and a vast field of active silence → retain at most one tiny source-derived colour as a memory point → integrate one short title plus one or two micro-elements with the line itself**.

The meaning comes from the source's actual pose, distance, intimacy, separation, waiting, movement, direction, time, or unfinished relation—not from adding stock philosophical symbols, tears, cages, hearts, moons, doors, or unrelated curves. Minimal image art, artist books, meditative drawing, modernist publishing, and experimental editorial design are construction influences rather than templates.

Reject the result as generic when an unrelated photo could replace the source without materially changing the core image, relation distance, line route, pauses, crossings, tiny accent, or copy. Also reject realistic line drawing, complex contours, decorative looping, calligraphic prettiness, meaningless abstract curves, smooth vector polish, literal background reconstruction, broad colour fields, photoreal shading, 3D volume, dense scenery, commercial advertising, or symbols not earned by the source.

## 011 visual system

### Source identity and one core proposition

- Privately lock at least three source-specific cues across contour, pose/orientation, opening, connection, overlap, negative shape, relationship distance, or dominant direction.
- Identify the most meaningful emotional tension, spatial relation, action direction, distance, state, or supported metaphor in the source. Convert those facts into the route and behaviour of the line rather than illustrating them with stock symbols.
- People keep pose, direction, clothing mass, and relational distance; animals keep body rhythm and head direction; plants keep growth gesture; architecture keeps skyline and defining openings; objects and vehicles keep functional silhouette and negative shape; landscapes keep one source-specific terrain or spatial relation.
- Keep one core image and one inseparable relation group. Its recognisable structure should emerge from the moving line and remain perceptible at a glance without becoming a complete literal outline or explanatory diagram.

### Line distance, pause, and active silence

- Use white or warm paper with overwhelming open space. The subject may be very small, offset, locally cropped, or suspended—never enlarged to fill the canvas or balanced like a logo.
- Let line-to-line distance, approach, separation, crossing, pause, and direction express time, loneliness, intimacy, waiting, movement, or incompletion.
- Every omission, connection, misalignment, extension, overlap, crossing, and unfinished edge must correspond to a source fact. The route should be quiet, fluid, natural, and simple without becoming easy decoration.
- Preserve breathing room as active silence. Do not fill the canvas, mechanically centre the image, or add generic rays, grids, dots, and curves simply to enrich it.

### Fine flowing continuous hand line

- Keep the line black or near-black, fine, flowing, and natural, with slight changes of width, pause, breathing, density, rhythm, friction, hesitation, and incompletion.
- Use contour omission, local connection, subtle misalignment, extension, overlap, or crossing to reorganise the subject. Each mark must carry recognition, relation, or emotional meaning.
- Allow faint ink absorption and paper tooth, but no broad watercolour painting, coloured-pencil fill, pastel blocks, heavy comic outline, or simulated glossy wire.
- Preserve flat depth. Reject realistic modelling, gradients, cinematic light, smooth Bézier perfection, metal 3D, clay, resin, plastic, and shadow effects.

### Near-monochrome ground and one memory point

- Use white or warm paper with black or near-black line as the dominant system.
- Allow at most one extremely small source-derived colour on one object, node, line segment, light point, or relation focus when that colour carries emotional or narrative meaning. It behaves like a deliberately preserved memory, never decoration.
- The accent occupies no more area than the single focus requires. Avoid repeated colour, multicolour fill, gradients, rainbow or brand palettes, muddy faux-vintage filters, and atmospheric shading.

## Copy and typography belong to 011

011 text undergoes the same spiritual distillation as the image and behaves like an artist-book annotation inside the line system—not a headline, slogan wall, UI label, or detached editorial block.

- Automatic copy derives one extremely short title from the source's visible or supported emotion, relation, action, time, distance, state, or metaphor, plus one or two micro-elements only when useful.
- A restrained philosophical line, number, or note may appear, but factual-looking dates, places, provenance, and numbers must be supplied or reliably established.
- Preserve exact user wording verbatim. Refine an editable direction only within permission while protecting audience, mandatory terms, tone, and semantic phrase breaks.
- Apply the unrelated-image swap test: generic lifestyle words that survive on another source must be rewritten.

Typography has its own 011 construction:

- **Role:** a quiet philosophical annotation that extends the line's meaning without explaining the image.
- **Voice:** still, thoughtful, implicit, poetic, meditative, and restrained.
- **Construction:** one short title plus one or two much smaller supporting elements; use fine weight, generous spacing, native small-cap equivalent, vertical setting, or asymmetry only when natural to the script.
- **Placement:** follow a line direction, stop at its endpoint, hide in open space, align with a subject contour, be crossed or divided by a line, or let one line become the text baseline, guide, or connection.
- **Material:** fine absorbed ink or a lightly imperfect printed line consistent with the black drawing.
- **Script:** use a native hand-made editorial equivalent for the resolved locale. Preserve natural Chinese, Japanese, Korean, Arabic, and Latin construction rather than imitating Latin handwriting across every script.

Resolve locale independently from command language:

```text
target market or audience > requested output language > direction language; if none is explicit, ask before generation
```

Localise by transcreation using native wording, rhetoric, punctuation, spacing, shaping, and semantic line breaks. Never infer nationality or audience language from appearance, clothing, scenery, filenames, metadata, or signs.

## Raster generation and privacy

Use the host's built-in bitmap image-generation capability by default and follow the available `imagegen` skill when exposed. View each local source before generation. Use one generation call per distinct asset; a wallpaper pack requires four calls. “Continuous line”, “minimal image art”, “meditative drawing”, and “artist-book editorial” describe appearance only and never authorise SVG, HTML, CSS, Canvas, diagrams, or programmatic drawing as the artwork.

If built-in bitmap generation is unavailable, use `scripts/configured_imagegen.py`, which reuses an already configured compatible bitmap route and emits sanitised status only:

```bash
python3 scripts/configured_imagegen.py probe

  --prompt-file /private/job-temp/transform-prompt.txt \
  --out /private/job-temp/design.png --size 1536x1024 --quality high
```

Judge readiness by actual bitmap capability, not a provider name or one environment variable. Never display, log, persist, or report providers, endpoints, headers, credentials, account identifiers, route configuration, prompts, or response bodies. Do not manually inspect credential files. The bridge's sanitised JSON is the complete allowed diagnostic surface.

An explicit invocation of `/xxd-panel-011` or `$xxd-panel-011` with a source image and requested output authorises generation through any already configured authenticated bitmap route available to the session. Do not ask for a second confirmation solely because the route changes. This does not authorise changing credentials, providers, billing, accounts, or global settings.

Only report generation as unavailable after both built-in capability and the bundled probe fail to establish a usable bitmap route. State the limitation narrowly and never guess the cause or identify the provider. Never substitute code-rendered art.

## Fresh-task and source boundary

Every invocation starts a fresh generation job unless the user explicitly asks to continue, audit, compare, edit, or reuse a named earlier result. Repeating the same source and parameters still means generating a new result in a new task directory. An old file can never satisfy a new request.

Use only images attached to the current invocation, explicit user paths, or a previously supplied image that the current request clearly identifies as “the same image”. Never broadly scan the Desktop, workspace, `~/Desktop/xxd/xxd-panel-011/`, or historical task folders to find a substitute source. If the intended source cannot be accessed, ask for it.

   ```text
      请分别输入手机、iPad、电脑、儿童手表的尺寸
   ```

5. Open one fresh job boundary and reserve the next unused sibling output directory for every source and selected mode. Confirm only current user-supplied sources, inspect each separately, and read the full prompt matching the working language:
   - Chinese: [references/xxd-panel-011-prompt.zh-CN.md](references/xxd-panel-011-prompt.zh-CN.md)
   - English: [references/xxd-panel-011-prompt.en.md](references/xxd-panel-011-prompt.en.md)
6. Privately lock: the principal subject or inseparable relation group; at least three identity, contour, pose, action, structure, or relation cues; the one core image; emotional tension; spatial relation; action direction; distance or state; any supported metaphor; line omissions, local connections, misalignments, extensions, overlaps, crossings, pauses, and unfinished edges; active-silence placement; the optional single memory colour; and the microtype-line relation. Do not invent unsupported biography, location, events, ownership, emotion, symbolism, or philosophical claim.
7. Lock one copy package per source and share it verbatim across selected modes by default; honour explicit per-mode overrides. Priority: explicit text-free request > exact user wording > editable user direction > source-derived automatic copy. Automatic copy uses one title plus zero to two supporting elements only when useful. Do not reuse one photo's copy for another unless asked.
8. Run `scripts/compose_panel.py --plan` for every selected mode and resolved canvas. Selected wallpaper-pack uses four `design-only` plans.
9. Generate each distinct transformed design alone at the planned aspect and preferably exact frame size. For paired modes, prepare the photographic panel separately. Never ask the model to generate both halves at once.
   Within the same current invocation, ordinary modes may reuse one newly approved transformed intermediate only when frame dimensions, aspect ratio, source facts, aesthetic instructions, typography, and locked copy are identical. Otherwise generate separately. Wallpaper assets are always generated separately.
10. For `independent`, generate four wallpapers directly from the source. For `linked`, generate and visually approve the anchor first; every derivative receives exactly the original source plus that same anchor. The source locks identity and content; the anchor locks only core-proposition grammar, fine flowing line character, pause and distance logic, active silence, tiny-memory-colour strategy, paper/ink material, and typography. Never chain derivatives.
11. Finalise every selected mode in menu order with `scripts/compose_panel.py`, reopen each PNG at normal and thumbnail size, and apply the acceptance gate. Retry only the faulty generated asset once when a hard invariant fails. After one failed correction, return the best result and name the unresolved issue rather than pretending success.
12. Return absolute paths in source order, then menu order 1→4. Wallpaper order is phone, iPad, desktop, watch.

## Composition commands

```bash
# Source-adaptive top-bottom
python3 scripts/compose_panel.py --plan --layout top-bottom --source photo.png
python3 scripts/compose_panel.py --source photo.png --design design.png \
  --out result.png --layout top-bottom

# Source-adaptive left-right
python3 scripts/compose_panel.py --plan --layout left-right --source photo.png
python3 scripts/compose_panel.py --source photo.png --design design.png \
  --out result.png --layout left-right

# Design-only
python3 scripts/compose_panel.py --source photo.png --design design.png \
  --out result.png --layout design-only

# One wallpaper, repeated separately for all four devices
python3 scripts/compose_panel.py --design phone.png --out wallpaper-phone.png \
  --layout design-only --size 1440x3200
```

`--size WIDTHxHEIGHT` overrides `--canvas` and source adaptation. Generate the design at the exact planned aspect; if exact pixels are unsupported, use a closest supported same-aspect bitmap and resample proportionally without cropping. Audit with the same layout used to build the result.
