# XXD Panel 030 · 真实自然材料编辑拼合

Turn each supplied photograph into one finished editorial assemblage made from visibly real natural materials. Preserve the real photograph only in paired modes; every transformed frame must keep the same source's proportion, contour, pose, direction, action, and relation while allowing recognisable leaves, petals, twigs, fruit, seeds, grass stems, bark, or dried leaves to carry the subject's actual shape. One simple rectangular colour or paper field establishes order without a fully drawn border. Most of the assemblage stays within it while one source-earned directional part grows naturally beyond it; generous whitespace, incomplete symmetry, minimal black hand marks, and lightweight copy keep organic accident and editorial discipline in balance.

Operational rules follow the shared XXD Panel workflow contract: four combinable modes; source-adaptive ordinary canvases; exact 50/50 paired geometry; linked or independent four-device wallpapers; copy and locale preflight; fresh generation jobs; privacy-preserving raster generation; and one fresh task directory per source and mode. Style-specific sections may refine aesthetics, copy hierarchy, and acceptance criteria but never override this contract.

## Non-negotiable contract

- One source photo may be processed in one or more selected modes. Each selected ordinary mode (`top-bottom`, `left-right`, `design-only`) produces one PNG; selected `wallpaper-pack` produces exactly four separate PNGs. Selecting all four modes therefore produces seven final files per source. Keep every mode in its own task directory and never combine modes, sources, or wallpapers into a grid, contact sheet, or overview.
- Resolve a non-empty ordered set of modes before generation: `top-bottom`, `left-right`, `design-only`, and/or `wallpaper-pack`. Accept one choice, multiple choices separated by `+`, Chinese/English commas or whitespace, natural-language names, or `全部` / `all`. Deduplicate repeated choices and execute in menu order 1→4. If none is specified, ask with the multiline multi-select menu in the workflow. Do not ask again when the set is already clear.
- When the selected set contains `wallpaper-pack`, require a second choice: `linked` or `independent`. A linked pack approves one anchor wallpaper, iPad by default, and makes every other device reference both the original photo and that same anchor. An independent pack gives every device only the original photo. Neither permits resizing or cropping one wallpaper into the others. Do not ask this follow-up when wallpaper mode is not selected.
- Paired modes split exactly 50/50. `design-only` and every wallpaper contain no visible source photograph, no seam, and no reserved photographic panel.
- Exact user pixels have highest priority, followed by an explicit ratio or destination. Otherwise ordinary modes adapt to the complete source: `top-bottom` = `W×2H`, `left-right` = `2W×H`, and `design-only` = `W×H`. Never impose the archived initial brief's 3:4 canvas as a silent default.
- Visible photography remains faithful. Allow only restrained editorial grading and environmental extension needed for an explicitly overridden canvas. Never stretch, distort, repaint, replace, or structurally alter the subject.
- The transformed frame must preserve identity, action, function, and emotion through at least three source-specific cues while building the subject from clearly identifiable real botanical materials whose natural shapes, textures, colour differences, and irregular edges remain visible. Most of the subject belongs to one simple rectangular colour or paper field; only a source-earned directional part crosses naturally. It is not tracing, a full illustrative outline filled with plants, geometry cut from leaves, children's leaf craft, stock bouquet collage, sticker art, dense scenery, or 3D.
- Copy has no silent default. Resolve automatic copy, exact custom copy, or text-free output before image generation. Automatic and custom modes also require a target language or locale. By default, one source-specific copy package is shared verbatim across all selected modes; explicit per-mode copy instructions override it.
- Render no logo, watermark, signature, colour swatch, UI, device mockup, decorative pseudo-text, or unrelated explanatory prose.

## Aesthetic motive lock

Modes and device ratios may change placement and aspect ratio but never the 030 motive. Every transformed frame must visibly express this chain:

**this exact photographed subject or inseparable relation → preserve identity, proportion, gesture, direction, action, function, emotion, and at least three defining cues → choose a small source-responsive set of real leaves, petals, twigs, fruit, seeds, grasses, bark, or dried foliage whose uncut forms can carry those cues → assemble the subject directly from their original contours, veins, fibres, colour variation, and broken edges → establish one simple source-harmonised rectangular colour or paper field without outlining all four sides → keep most of the assemblage inside while one genuinely directional part grows beyond the boundary → balance organic accident, clear weight, incomplete symmetry, and generous whitespace → add only the few black hand marks required for expression, connection, or rhythm → align one short title and only useful micro-notes with the field edge or a natural stem direction**.

The warmth comes from finding an unexpectedly exact natural form for the photographed identity—not from cute faces, craft-school nostalgia, stock wreaths, scrapbook props, stickers, or decorative florals. Botanical specimen handling, temporary land-art assemblage, tactile editorial still life, and modern independent publishing are material influences rather than templates.

Reject the result as generic when an unrelated photo could replace the source without materially changing material choice, subject contour, gesture, rectangular-field relation, directional crossing, natural colour character, or line/copy alignment. Also reject neatly clipped leaf geometry, a black contour enclosing plant pieces, arbitrary species, symmetrical wreaths, stock bouquets, evenly scattered foliage, children's leaf animals, artificial paper cut-outs, sticker shadows, dense scenery, commercial-cartoon styling, or decorative plants not earned by the source.

## 030 visual system

### Recognisable subject built from real natural materials

- Privately lock at least three source-specific cues across contour, pose/orientation, function, proportion, material, colour, opening, connection, overlap, negative shape, or relationship distance.
- Build the principal subject or inseparable relation directly from visibly real leaves, petals, twigs, fruit, seeds, grass stems, bark, or dried leaves. Preserve their native silhouette, veins, fibres, colour variation, tears, curls, and irregular edges instead of cutting them into exact geometry.
- People keep pose, direction, clothing mass, and relational distance; animals keep body rhythm and head direction; plants keep growth gesture; architecture keeps skyline and defining openings; objects and vehicles keep functional silhouette and negative shape; landscapes keep one source-specific terrain or spatial relation.
- Keep one principal subject or inseparable relationship. Every botanical piece must carry identity, action, relation, or necessary structure; remove filler sprigs and ornamental scatter.

### One quiet rectangular field and natural crossing

- Establish exactly one simple rectangular colour or paper region, with its hue, temperature, and value harmonised to the current source. Let crop or tonal difference imply its edges; do not deliberately draw a complete border.
- Keep most of the assembled subject within the field. Allow only a small, most directional part—such as a stem, tail, limb, roofline, handle, or motion vector translated through natural material—to extend beyond it because the source calls for that movement.
- Balance field, assemblage weight, positive/negative shape, incomplete symmetry, and large quiet whitespace as one system. The crossing should feel as if the plant material happened to grow from the page, never posed to demonstrate a trick.
- Reject multiple panels, repeated frames, arbitrary edge-breaking, scenic backgrounds, patterns, scattered icons, stickers, or decorative borders.

### Material truth and almost no black line

- Preserve photographic material evidence: leaf veins, petal translucency, fruit skin, seed scale, grass fibres, bark cracks, dried edges, natural curl, and small colour differences remain legible.
- Never draw the entire subject first and fill it with plants. The materials themselves establish silhouette and mass; their overlaps and contact points must be physically plausible on a flat working surface.
- Use fine relaxed black line only for an eye, mouth, tiny expression, action cue, necessary connector, short rhythm mark, or restrained handwritten trace. It never encloses the whole subject or dominates material edges.
- Keep shadows soft and contact-based so the pieces feel real but flat. Reject plastic foliage, digitally painted plants, artificial cut-paper geometry, thick outline, glossy 3D, dramatic studio depth, and sticker drop shadows.

### Source-derived botanical colour character

- Extract the source's most vital and recognisable colour character, then translate it through the actual colours available in the selected natural materials rather than dyeing everything to match.
- Preserve the composite variation among green leaves, petals, fruit, bark, twigs, seeds, and dried foliage; edit the selection so it remains coherent and alive rather than uniformly tinted or chaotic.
- Use a pale or softly coloured background and one harmonised rectangular field so the materials stay central. Never reuse one photograph's plant palette for another by default.
- Avoid fixed green-and-flower recipes, rainbow species sampling, artificial recolouring, muddy filters, neon colour, universal beige, and colour unrelated to the source.

## Copy and typography belong to 030

030 text behaves like a lightweight editorial annotation placed in dialogue with the rectangular field and one natural material direction—not a conventional poster headline, botanical label system, UI, specimen database, or detached advertising overlay.

- Automatic copy derives one concise title from the source's visible or supported identity, emotion, action, relation, or metaphor without inventing a story.
- Prefer one restrained title plus zero to two very small supporting elements. A number, place, or year appears only when supplied or reliably established.
- Preserve exact user wording verbatim. Refine an editable direction only within permission while protecting audience, mandatory terms, tone, and semantic phrase breaks.
- Apply the unrelated-image swap test: generic lifestyle words that survive on another source must be rewritten.

Typography has its own 030 construction:

- **Role:** a light editorial counterweight to organic material and the rectangular field.
- **Voice:** intelligent, fresh, quiet, poetic, exact, and restrained.
- **Construction:** one short title plus zero to two truly useful micro-notes; refined spacing and a light weight keep the materials primary.
- **Placement:** align with a field edge, hover in whitespace, or answer the direction of one twig, stem, or leaf; never cover a defining natural form.
- **Material:** fine editorial type or a tiny relaxed hand mark compatible with the source and locale; never a huge display headline, rustic craft font, or faux specimen label.
- **Script:** use native construction, joining, direction, punctuation, spacing, and legibility for the resolved Chinese, Japanese, Korean, Arabic, or Latin locale.

Resolve locale independently from command language:

```text
target market or audience > requested output language > direction language; if none is explicit, ask before generation
```

Localise by transcreation using native wording, rhetoric, punctuation, spacing, shaping, and semantic line breaks. Never infer nationality or audience language from appearance, clothing, scenery, filenames, metadata, or signs.

## Raster generation and privacy

Use the host's built-in bitmap image-generation capability by default and follow the available `imagegen` skill when exposed. View each local source before generation. Use one generation call per distinct asset; a wallpaper pack requires four calls. “Real leaves”, “petals”, “twigs”, “botanical assemblage”, and “editorial paper field” describe photographed material appearance only and never authorise SVG, HTML, CSS, Canvas, diagrams, or programmatic drawing as the artwork.

  --prompt-file /private/job-temp/transform-prompt.txt \

Judge readiness by actual bitmap capability, not a provider name or one environment variable. Never display, log, persist, or report providers, endpoints, headers, credentials, account identifiers, route configuration, prompts, or response bodies. Do not manually inspect credential files. The bridge's sanitised JSON is the complete allowed diagnostic surface.

An explicit invocation of `/xxd-panel-030` or `$xxd-panel-030` with a source image and requested output authorises generation through any already configured authenticated bitmap route available to the session. Do not ask for a second confirmation solely because the route changes. This does not authorise changing credentials, providers, billing, accounts, or global settings.

Only report generation as unavailable after both built-in capability and the bundled probe fail to establish a usable bitmap route. State the limitation narrowly and never guess the cause or identify the provider. Never substitute code-rendered art.

## Fresh-task and source boundary

Use only images attached to the current invocation, explicit user paths, or a previously supplied image that the current request clearly identifies as “the same image”. Never broadly scan the Desktop, workspace, `~/Desktop/xxd/xxd-panel-030/`, or historical task folders to find a substitute source. If the intended source cannot be accessed, ask for it.

## Composition commands

```bash
# Source-adaptive top-bottom
python3 scripts/compose_panel.py --plan --layout top-bottom --source photo.png
python3 scripts/compose_panel.py --source photo.png --design design.png \
  --out result.png --layout top-bottom

# Source-adaptive left-right
python3 scripts/compose_panel.py --plan --layout left-right --source photo.png
python3 scripts/compose_panel.py --source photo.png --design design.png \
  --out result.png --layout left-right

# Design-only
python3 scripts/compose_panel.py --source photo.png --design design.png \
  --out result.png --layout design-only

# One wallpaper, repeated separately for all four devices
python3 scripts/compose_panel.py --design phone.png --out wallpaper-phone.png \
  --layout design-only --size 1440x3200
```

`--size WIDTHxHEIGHT` overrides `--canvas` and source adaptation. Generate the design at the exact planned aspect; if exact pixels are unsupported, use a closest supported same-aspect bitmap and resample proportionally without cropping. Audit with the same layout used to build the result.
