# 落地使用指南

## 零、先确认你拿的是「附件版」还是「正文版」

`build_prompt.py` 的输出头部会标出 `提示词来源：附件原文 / 笔记正文`。

- 标 **附件原文** 的 20 条，是作者放在笔记附件里的**完整版**（平均 1129 字），直接整段用，不需要补东西。
- 标 **笔记正文** 的 119 条，是笔记正文（平均 719 字），同样可用；但如果你发现某条正文读起来像"介绍"而不是"指令"，那说明这条的完整版在附件里而这次没取到——用 `find_attachment.py --no <系列号>` 确认一下。

## 一、画布与比例

- 原帖所有对照图都是 **3:4 竖版 1080×1440**，上下各占一半。建议保持一致，效果最接近原帖。
- 想发别的比例：
  - 小红书竖版 3:4 / 9:16 → 把「下半部分」改成「画面右侧 / 下部区域」并相应调整留白描述。
  - 横版 16:9 → 改成左右对照（左原图 / 右风格化），留白逻辑不变。
- 比例改动要同步改提示词里的「上半部分 / 下半部分」字样，否则模型会按竖版硬排。

## 二、原图怎么给模型

| 场景 | 做法 |
| --- | --- |
| 模型支持图像参考（GPT Image / Seedream / Nano Banana 等） | 直接把原照片作为参考图，配提示词原文，让它自己完成「上半原图 + 下半重构」 |
| 模型只能文生图 | 把「从上方照片中提取」改成文字描述：「从以下画面中提取 2–4 种颜色：<描述>」。提示词里「上半部分」的表述可删掉 |
| 只想要下半部分那一张 | 把开头一句改成「整张画面按以下语言重构」，删掉所有「下半部分」字样 |

## 三、颜色替换（最常见的一次改动）

提示词第 4 段永远是「从上方照片中提取 2–4 种最有辨识度、最有生命力的颜色」。模型看不到原图时，把这句话替换成：

> 配色以 **#A8C4A0 灰绿 / #E8B96A 暖杏 / #2F3B4C 深墨蓝** 为主色系，适度提亮、提纯、去灰……

保留后面的「基底大面积米白／暖白」和「避免灰脏、暗沉、荧光色和廉价高饱和」不变——**这两句是效果稳定器，删了会崩**。

## 四、常见失败与修法

| 症状 | 原因 | 修法 |
| --- | --- | --- |
| 出图像「加了个滤镜」，还是原图的构图 | 授权句没写，或写了但被模型忽略 | 把「真正赋予模型重新导演画面的权力……」整句提到提示词最前面，并加一句「必须重新构图，不得沿用原图取景」 |
| 画面太满、没有高级感 | 留白比例没写死 | 加「主体只占画面约 15%–20%，其余为大面积纯净留白」；再补「禁止满版、禁止背景装饰」 |
| 颜色发灰发脏 | 缺少「提亮、提纯、去灰」 | 补齐三连，并显式禁止「莫兰迪化、灰调、低饱和复古」 |
| 颜色太艳像廉价广告 | 缺少高饱和禁令 | 补「避免廉价高饱和、荧光色、糖果色」 |
| 主体认不出是原图那个人/物 | 抽象过头 | 补「必须保留决定身份与情绪的关键特征：<列出 2–3 个特征>」 |
| 出现了奇怪的写实照片元素 | 风格段的媒介词不够强 | 补一句「全画面统一为 <媒介> 语言，不允许出现照片质感、写实光影、立体渲染」 |
| 文字乱码/多余文字 | 第 5 段没约束 | 补「除指定文字外不添加任何文字、字母、编号或水印」 |

## 五、变体玩法

- **同风格换主体**：只用风格那一条，把「上方照片」换成新照片。风格名 = 可复用的零件。
- **同风格换情绪**：在配色段加「整体偏向暮色 / 清早 / 雨后的情绪」。
- **混风格**：拿 A 的构图段 + B 的材质段 + C 的配色段拼。骨架通用，段落可拆装——这是这套提示词最实用的地方。
- **系列化**：同一风格出 6–9 张，横竖各一组，做成一整套视觉，比单张更有辨识度。

## 六、批量出图建议

- 先用 `search_style.py --top 20` 挑社区验证过的高收藏风格，命中率更高。
- 一次只改一个变量（要么换风格、要么换主体、要么换文字），否则出问题不好定位。
- 记录「风格号 + 主体 + 文字 + 成图」，方便复用。工作室里可以按 P 号建命名规范：`P165_中央撕纸_上海外滩_v1`。

## 七、引用与署名

- 用到某个风格时，把原帖链接一起带上：`风格参考：@小小东 P165 中央撕纸揭景风 <链接>`。
- 商业项目请先取得原作者授权；不要直接搬运原帖对照图当作自己的案例。
