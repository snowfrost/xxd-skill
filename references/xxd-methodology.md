# XXD 方法论总纲

> 蒸馏自 @xiaoxiaodong01（小小东）GPT-Image-2 美学提示词系列（2025.11 加入 X，2,800+ 帖，vip.xiaoxiaodong.ai 提示词库 22,267 套）

## 一、母模板：上下分割双联法

80% 的提示词共用同一结构骨架：

```
请将我上传的每一张照片分别制作成一张独立的高级设计海报，不多图拼接，每张照片单独输出。
整体采用3:4竖版构图，上下两个区域高度严格1:1，各占画面50%。

上半部分：保留原始照片（主体身份、结构、姿态、真实质感、自然光影、原有色彩氛围）
+ 仅轻微高级摄影调色 → 艺术杂志/独立出版物/展览摄影质感
+ 为适配画幅可自然扩展天空/地面/环境，但不得拉伸、扭曲、改变主体

下半部分：提取照片中最具识别性的主体、轮廓、姿态与叙事关系，
重构为【风格插槽】描述
```

**通用收尾**：开头和结尾各放一组表情符号（如 `😂😌😜🥲` ... `😍😋😊🙃`），作为模型的"风格边界标记"。

## 二、风格插槽（下半部分可替换模块）

### 1. 剪纸/纸艺微缩景观（VOL.051/052）
- 主体+少量辅助元素转成纸/卡纸/软陶/木片手工模型
- 一条狭长悬浮景观基座 + 一个核心主体 + 大面积留白
- 强调真实手工触感：纸纤维、折边、切口、层叠厚度、毛边
- 避免：塑料3D、玩具感、儿童手工感、复杂堆积、过度可爱、电商展示感

### 2. 木刻版画（VOL.049）
- 删减复杂背景，只留决定识别度的轮廓/比例/明暗分区
- 线条带刀刻笨拙感：粗细不均、边缘发毛、局部断裂、缺口、错位
- 色块边缘：干刷、漏印、缺墨、粗颗粒
- 构图：单一视觉锚点 + 大面积留白 + 不完整边缘
- 配色：奶油白/象牙白/浅粉/雾绿/浅蓝/嫩黄/淡橙，低中饱和高明度

### 3. 矢量旅行海报（VOL.050）
- 一个主视觉焦点 + 2-4 个辅助元素（环境气质/日常方式/地方感）
- 日系文具感、精品贴纸、editorial travel branding
- 简洁几何形、柔和轮廓、统一线重、平涂色块
- 人物仅 3-6 个小尺度，无单一主角
- 每张独立视觉身份，禁止套模板

### 4. 包装 MOCKUP 系统（VOL.001）
- 主体特征提炼为核心图形/插画符号/纹样/色块/识别元素
- 5-8 种载体：纸袋/盒/套盒/标签/吊牌/票券/卡片/贴纸/封套/杯套/挂件
- 1-2 主包装为视觉重心 + 模块化组合
- packaging identity presentation board（非商品陈列/杂乱拼贴）

### 5. 水彩编辑插画（Topview 版）
- 现代主义编辑插画 + 包豪斯平面构成 + 儿童绘本 + 稚拙艺术 + 时尚速写
- 水彩/水粉/彩铅/粉蜡笔/干刷混合质感
- 保留纸张颗粒、透底、笔触断裂、边缘毛糙、旧印刷套色偏差
- 背景大面积留白

### 6. 厚涂微景观（panel-046）
- 调色刀厚涂油彩微缩主体 + 源图派生的对角支撑面
- 暖白纹理留白 + 艺术出版物级克制排版

## 三、上层建筑五件套（每篇必备模块）

| # | 模块 | 标准表述 |
|---|---|---|
| 1 | 构图 | 单一视觉锚点、大面积留白、明确前后层次；根据主体视觉重心决定位置与尺度，可居中、偏置、轻微裁切 |
| 2 | 配色 | 浅粉蓝/雾蓝/天空蓝/空气感冷调蓝建立主氛围 + 象牙白/奶油白/浅米色/柔和灰绿/建筑中性色平衡 + 少量 dusty rose/muted blush 点缀；柔和、通透、略微去饱和 |
| 3 | 材质 | 真实手工触感：纸纤维、折边、切口、颗粒、毛边、制作误差；柔和自然漫射光 + macro photography 质感 |
| 4 | 文字 | 从照片的地点/主体/主题/情绪提炼 1-3 词简短标题；克制优雅排版，像艺术家签名而非商业标题；不固定使用年份 |
| 5 | 禁忌 | 塑料3D、玩具感、儿童手工感、过度可爱、电商展示感、复杂堆积、模板感、灰脏陈旧、光滑矢量描边、普通滤镜 |

## 四、批量出图咒语

```
连续生成10张图片,每张都是不同的角色逻辑,还有金句逻辑,还有配色和排版逻辑,类似于ppt,生成10张确保彼此的排版差异
```

配套技巧（源自小小东）：
1. 思考力度高点
2. 作图模式开启
3. 实在不行就 work 模式
4. 每天批量作图有上限，轻易别大量过度

## 五、词义视觉化（大字概念海报）

- **核心**：文字本身就是主题，图像是对文字的深化表达
- **构图**：极简主场景 + 承载面（舞台/土地/台基/底座）+ 1-3 个演绎主体 + 巨型文字骨架
- **文字嵌入**：主体站字前/嵌入字内/字为背景墙/字被切割遮挡穿越借位
- **色彩**：2-4 主色（1 强主色 + 1 纸感浅色/低彩中性色 + 1 深色支撑 + 1 极少量强调色）
- **质感**：拼贴/丝网/石版/版画/纸张颗粒/克制噪点
- **禁忌**：字效海报、文字贴背景、假署名假编号假坐标、模板海报

## 六、东方编辑美学（知识卡片/课件）

- 极大汉字/数字/符号做空间骨架，允许被画面边缘裁切
- 文字层级：最大字=视觉重量；中等字=章节感；小字=知识密度；英文/拼音=节奏细标
- 色彩：低饱和浅底（米白/宣纸灰）+ 沉稳主色（墨灰/炭黑/深褐/深青）+ 朱印式强调色
- 强调色温度：学术→冷（深蓝/铁灰）；文化手作→温热（朱砂/陶土/枣红）；科技金融→锋利低饱和
- 版式：不完全对称东方网格，信息块如漂浮小岛

## 七、中英双语转换原则

- 中文版用于中文对话/国内平台；英文版（Please turn each photo I upload into...）用于国际平台
- 结构一致：开头表情符号 → 总任务 → 上半保真 → 下半风格化 → 配色 → 材质 → 文字 → 结尾表情符号
- 英文版措辞更强调 editorial / premium / understated / spacious 等设计术语
