## 一句话本质

把**任意一张普通照片**，重构成一张**「上原图 / 下风格化」的编辑感审美海报**。
所有提示词都是同一台机器换零件——机器不变，只换「风格零件」。

## 五段式骨架

正文平均 775 字、5–6 段，段落顺序几乎从不改变：

| # | 段落 | 作用 | 固定句型（原文） |
| --- | --- | --- | --- |
| 1 | **主体提取** | 声明「只提取不复制」 | 「下半部分只提取照片中最具识别性的**主体、轮廓、结构、姿态与叙事关系**，重新做美术判断」＋「不要完整复制照片，不要逐物转绘，不要保留所有对象」＋「使人一眼识别它与上方照片之间的对应关系」 |
| 2 | **构图 / 留白** | 决定 80% 的"高级感" | 「构图保持**小尺度主体与超大量留白**的关系」＋「主体只占约 20%–25%」＋「可偏心、贴边、悬置或局部裁切」＋「留白不是空背景，而是画面的一部分」＋「宁可少，也不要填满」 |
| 3 | **风格 / 材质** | 唯一的变量，风格名就在这一段 | 「重构为 **<风格英文名>**」＋ 媒介词（纸雕 / 版画线描 / 厚油墨浮雕 / 位图栅格 / 钢笔淡彩…）＋ 材质细节（纸纹、切边、颗粒、层叠厚度、dithering） |
| 4 | **配色** | 从原图取色，再"提纯" | 「从上方照片中提取 **2–4 种最有辨识度、最有生命力的颜色**重新调制，适度**提亮、提纯、去灰**」＋ 大面积浅底（米白 / 暖白 / 象牙白）＋ 极少量点睛色＋ 禁忌色 |
| 5 | **文字** | 留 5% 给排版 | 「文字只作**极少量编辑性介入**，不限制语种，也不预设固定标题或编号」＋「自由生成少量字词或短句，安静地落在留白区域」 |

## 三条贯穿全篇的铁律

1. **提取 ≠ 复制。** 每条都在禁止「完整复制 / 逐物转绘 / 保留全部对象」。风格化的前提是**先做减法**。
2. **留白是主角，不是背景。** 出现频率最高的词就是「超大量有意识的留白」。它承担空气、距离、停顿、诗意，与主体**同等重要**。
3. **提色三连：提亮、提纯、去灰。** 从原图取 2–4 色，绝不让原图的灰脏原样带进成品。

## 授权句（决定成败的一句）

多数条目会插入这句，把「构图不行」的锅从模型身上拿走（139 条里 51 条含「重新导演 / 救成一张成立的作品 / 重新做美术判断」，其中 **43 条逐字写着「重新导演」**；越晚期的作品写得越全）：

> 真正赋予模型重新导演画面的权力：哪怕原图构图差、背景乱、主体小，也要通过**删减、重组、裁切、尺度变化和留白**，把它救成一张成立的作品。

写自己的提示词时**一定要抄这句**。没有它，模型会老老实实复刻原图，出图立刻变"滤镜"。

## 构图工具箱（第 2 段可换的零件）

| 零件 | 特征 | 代表风格 |
| --- | --- | --- |
| 越界 / 破框 | 主体局部穿出色场或框架边界，`break-the-frame` | 框景色场越界风、留纸白叠刷色场风 |
| 居中章印 | 小小一枚，落在大面积空白正中 | 居中纯色章印风、白衬剪纸绘本风 |
| 撕裂揭景 | 一道毛边裂缝作为视觉核心 | 中央撕纸揭景风 |
| 色场 / 第二画布 | 不规则矩形手工色场，四周留白边 | 框景色场越界风、色场基座纸艺风 |
| 微缩 / 等距 | 主体压缩成模型般的小体块 | 等距浮雕微缩风、水墨建筑微景风 |
| 小图大留白 | 主体仅占 15%–25% | 异形微岛版画风 |

## 材质词表（第 3 段的动词库）

- **纸系**：纸纤维、切边、毛边、压痕、层叠厚度、镂空、撕贴、拼贴、暖琥珀背光
- **印系**：厚油墨堆叠压印、油墨颗粒、浅浮雕起伏、极轻侧光、拓印
- **线系**：寻找线、重复线、松散速写墨线、不完全闭合、建筑制图线、等高线
- **数字系**：位图栅格、dithering、字符网点、低分辨率单元、有限像素色板、无抗锯齿硬边
- **绘画系**：淡彩晕染、轻薄水彩、淡墨虚染、移轴浅景深

## 配色系统

- 基底永远是大面积浅色纸面（米白 / 暖白 / 象牙白 / 奶油米白 / 浅纸色）——**先造"纸"，再放东西**。
- 主体取原图 2–4 色的**提纯版**，低饱和但有精神。
- 点睛色不超过 1%，常用朱砂红、陶土橙、暖橙。

## 文字规则

- 不预设固定标题，让模型自己根据主体/地点/情绪生成。
- 位置永远在留白区，**不与主体抢焦点**。
- 允许中英混排、位图字体、编号、注记等实验排版（见 字符网点实验风）。

读法：**「灰脏 + 暗沉 + 沉闷 + 脏灰 + 发旧 + 暗淡」这一族占了绝大多数**，配色的禁忌几乎条条都写「避免灰脏、暗沉」，紧接着又要「避免廉价高饱和 / 荧光色」——**两边都堵死，只留中间那条清透的窄路**，这是它出图稳定的关键。风格类的禁忌则集中在「光滑矢量」「塑料 3D」「照片滤镜」，作用是防止模型滑回写实。

## 命名法

`<四到六字描述> + 风`：异形微岛版画风、琥珀透光纸雕小景风、留纸白叠刷色场风、波形厚墨浮雕风、中央撕纸揭景风、水墨建筑微景风、居中纯色章印风、字符网点实验风、复古像素留白风、一点透视淡彩风。

命名即定位——**先把风格压缩成一个好记的名字，再写提示词**，写的时候不容易跑偏。

不要完整复制照片，不要逐物转绘，不要保留所有对象；主动删去绝大多数背景与无关细节，

真正赋予模型重新导演画面的权力：哪怕原图构图差、背景乱、主体小，也要通过删减、重组、
裁切、尺度变化和留白，把它救成一张成立的作品。

下半部分重构为【风格名 + 风格英文名】：【媒介与材质词】【造型与线条语言】【细节机理】。
不要【这个风格最怕的东西，如光滑矢量 / 塑料3D / 照片滤镜】。

构图保持小尺度主体与超大量留白的关系，主体只占约 20%–25%，可偏心、贴边、悬置或局部裁切。

使色彩鲜活、清透、温暖而不刺眼。以米白 / 暖白 / 象牙白为大面积基底，仅允许极少量
【点睛色】作为不到 1% 的视觉强调。避免灰脏、暗沉、荧光色和廉价高饱和。

文字只作极少量编辑性介入，不限制语种。可根据主体、地点、情绪或隐喻自由生成少量字词或短句，
